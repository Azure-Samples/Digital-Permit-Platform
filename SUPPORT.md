# Support

This project is provided as a sample and is not covered by a Microsoft standard support programme or service-level agreement.

## Community support

Use GitHub issues for reproducible problems in the unmodified sample, documentation corrections, and focused feature proposals. Before opening an issue:

1. search existing issues;
2. use the latest default branch;
3. follow the troubleshooting guide;
4. remove secrets, subscription IDs, tenant IDs, personal data, and customer data from logs;
5. include operating system, Node.js, `azd`, Azure CLI, and relevant package versions.

## Azure support

For Azure service incidents, quota, billing, capacity, or subscription-specific failures, use the [Azure support options](https://azure.microsoft.com/support/options/) associated with the target subscription.

## Security

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
